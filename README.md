# AI 销售定向营销 App

> 给一线销售个人的 AI 表达决策助手：把销售脑子里的客户认知整理成画像，按画像生成三版话术，人工确认后再触达。不做运营后台的批量群发，只做它做不到的事——对"这个人"说"这句话"。

课程作业项目（第三周）：利用 AI 技术，帮助销售人群根据用户画像特征进行定向营销推广。

## 北极星指标

**每周产出有效触达的销售数**——一周内走完"画像 → AI 生成 → 人工确认 → 登记发送"完整闭环的去重销售人数。

## 目标用户

一线销售个人（不是运营团队）。三类典型：医美 To C 私域销售、 B2B 企业软件销售、美妆电商社群销售。共性：缺"对谁说什么"的判断而非话术模板；"AI 打草稿、人做决定"是信任底线。

## 核心功能（MVP）

| 编号 | 需求 | 说明 |
|------|------|------|
| R01 | 客户画像卡 | 一句话整理成五维画像卡（基本信息/行为特征/在意什么/上次聊到哪/客户阶段），人工可改 |
| R02 | 按画像生成话术 | 按画像一次生成三版（正式版/亲切版/玩梗版），风险词标红，每版标注用到的画像信息点 |
| R05 | 人工确认机制 | 生成 → 预览可改 → 复制 → 手动登记，只生成不真发 |
| R09 | 触达记录与效果回看 | 登记触达（渠道/客户反应），列表回看，计入有效触达 |
| R10 | 五层分群与分层策略 | 新用户/活跃/高价值/沉睡/流失，AI 初判＋人工可改，每层一句话策略＋打扰风险提示 |

简化版：R03 打扰风险提示（一句话，并入策略卡）、R04 表达对象选择（技术型/业务型/老板型）、R08 System Prompt 约束三版语气。

二期（本期不做）：R06 多渠道一键触达、R07 语音/拍照快速录入。

## 画像五维

| 维度 | 回答的问题 | 内容 |
|------|-----------|------|
| 基本信息 | 他是谁 | 称呼、年龄、性别、职业 |
| 行为特征 | 他做过什么 | 客观事实：买过什么/客单价带/购买频次（RFM 简化版）＋意向等级，可分群筛选 |
| 在意什么 | 他怕什么、图什么 | 一句话主观动机，决定话术卖点和语气 |
| 上次聊到哪 | 上次接触的一句话 | 决定开场白 |
| 客户阶段 | 现在用什么策略 | 五层之一 |

逻辑骨架：身份事实 → 行为事实 → 动机推断 → 关系状态。

## 五层分群判定（从上到下，命中即定层）

1. 流失（一票否决）：明确拒绝 / 拉黑 / 长期无响应
2. 高价值：成交过或高意向（价值优先于新近度）
3. 沉睡：有过互动但超 30 天无互动
4. 新用户：无任何历史互动
5. 活跃：默认层

## 技术方案

前后端分离（方案 B）：

- **后端**：Python Flask，3 个 AI 代理接口（一句话整理画像卡 / 五层分群＋策略 / 按画像生成三版话术）＋ 画像/话术/触达记录 CRUD，SQLite 单文件数据库，同时托管前端单文件。
- **前端**：单文件 HTML，4 个 Tab（画像录入/分层洞察/话术生成/触达记录）＋ 设置页，调自家后端 `/api/*`。
- **AI**：千问百炼 OpenAI 兼容模式（`qwen-plus`），Key 存后端环境变量，前端不接触。
- **部署**：2 核 4G 云服务器，systemd 开机自启。

## 快速开始（本地）

```bash
cd demo/server
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # 填入 BAILIAN_API_KEY
python app.py
# 浏览器打开 http://127.0.0.1:5000
```

服务器部署见 `demo/server/` 包内的部署提示词（交由 AI 按步骤执行）。

## 竞争定位

与运营后台（微伴助手、纷享销客等）互补非替代：画像数据来源不同（系统行为 vs 销售个人认知）、决策权不同（运营配 SOP vs 销售自己决策）、场景不同（群发 vs 单点）。长期壁垒是销售个人视角的画像数据。
